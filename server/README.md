# 용의 귀환 · 게임 서버

게임은 기본으로 공개 MQTT 브로커(`broker.emqx.io`, 실패 시 `broker.hivemq.com`)를 통해
같은 서버(01~04)를 고른 플레이어끼리 연결됩니다 (서버당 최대 100명).

공개 브로커는 무료지만 보장이 없으므로, 안정적으로 운영하려면 이 서버를 직접 띄우고
게임 주소 뒤에 `?broker=wss://내서버주소` 를 붙여 접속하면 됩니다.

```
cd server
npm install
PORT=8080 node broker.js        # MAX_PER_SERVER=100 (기본)
```

- 채널(토픽): `rotd1/<서버>/z/<지역>` 위치·동작, `/chat` 전체 채팅, `/g/<길드>` 길드 채팅,
  `/w/<플레이어>` 귓속말, `/hb` 접속자 목록
- 서버마다 100명이 차면 새 접속을 거절합니다. 게임 토픽 외의 발행과 2KB 넘는 메시지는 막습니다.
- HTTPS 게임 페이지에서 접속하려면 `wss://`(TLS)가 필요합니다. 호스팅 서비스의 HTTPS 프록시 뒤에 두세요.

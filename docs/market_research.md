## 3. 한국 이용자가 원하는 것과 불만

### 3.1 불만 (피해야 할 것)

1. **P2W 피로:** 20~30대는 "과금 없이는 강해질 수 없는 구조", 반복 과금, 새로운 경험 부족에 지쳤다고 답했습니다. 확률형 중심 BM은 결국 신규 유입을 막는 장벽이 됐다는 분석입니다([바이라인네트워크](https://byline.network/2026/04/17-569/), [게임제너레이션](https://www.gamegeneration.or.kr/article/045a8130-7f48-467e-8fdf-3d9c7f8aff47)).
2. **확률 불신:** 메이플 키우기 확률 오류와 전액 환불 사례처럼 확률은 신뢰 문제로 바로 이어집니다. 2024년 3월 22일부터 확률 정보는 게임 안, 홈페이지, 광고에 모두 표시해야 합니다([정책브리핑](https://www.korea.kr/multi/visualNewsView.do?newsId=148924522), [한국콘텐츠진흥원](https://www.kocca.kr/global/2023_11+12/sub02_02.html)).
3. **패스·구독도 가격이 바뀌면 반발:** 아이온2 시즌2 사례처럼 "착한 BM"도 가격을 올리거나 기간을 줄이면 곧바로 논란이 됩니다.
4. **'매일 접속' 강요:** 최근 MMORPG는 체류 시간 경쟁 대신 이탈 방지와 접속 부담 줄이기로 방향을 바꾸고 있습니다([네이트/2026.9](https://m.news.nate.com/view/20260910n30177), [시사저널e](https://www.sisajournal-e.com/news/articleView.html?idxno=423250)).

### 3.2 원하는 것 (파고들 기회)

- **힐링·생활·소셜:** 마비노기 모바일의 10~20대 비중 73%는 "경쟁보다 함께 노는 MMO"를 원하는 수요가 있다는 증거입니다.
- **예측 가능한 지출:** 이용자는 월 지출을 미리 계획할 수 있는 멤버십·패스를 선호합니다(아이온2 개편 논리).
- **자동 사냥:** 한국 이용자에게 자동 사냥은 "기본 기능"에 가깝습니다. 다만 자동 사냥만으로 끝나는 게임은 "할 게 없다"는 평가를 받습니다. 성장은 자동으로, **레이드·PvP·시장은 수동으로** 나누는 방식이 좋습니다. **[추정: 업계 통념]**
- **설치 없는 접근:** 게임 이용률이 떨어지는 지금은 "링크 하나로 바로 플레이"가 가장 강한 진입 장벽 해소책입니다. **[추정]**

### 4.2 규모 감각 **[추정]**

- 동접 200명 ≈ DAU 1,000~1,500명(동접/DAU 비율을 15~20%로 가정)
- 결제 전환 3%, 결제자 월평균 7,000원 → 월 **약 21만~32만 원**
- 여기에 후원 구독 50명 × 4,900원 ≈ 월 25만 원
- → 초기 목표는 **"서버비 + 에셋 비용을 벌기"**(월 50만 원 안팎)가 현실적입니다. 서버를 여러 대로 늘리기 전까지 큰 매출은 기대하기 어렵습니다.

**국내 등급분류(필수 확인).** 국내에서 게임을 서비스하려면 등급분류가 필요합니다. Google Play·원스토어에 올리면 스토어의 자체등급분류로 처리되지만, **자체 웹사이트에서 서비스하는 웹게임은 게임물관리위원회(GRAC)에 직접 신청**해야 합니다. 개인 개발자는 수수료 50%가 감면되고, 비영리 게임물은 면제되며, 심의에는 약 10~15일이 걸립니다([아주경제](https://www.ajunews.com/view/20231004170609661), [게임메카](https://www.gamemeca.com/view.php?gid=1741742), [토스 앱인토스](https://toss.im/apps-in-toss/blog/game_rating_classification)). 정확한 금액은 [grac.or.kr](https://www.grac.or.kr/institution/etcform01.aspx)에서 확인해야 합니다. **[금액 미검증]** 유료 결제를 붙이는 순간 "비영리"가 아니게 되므로, 결제 도입 전에 등급분류를 받아야 합니다. PvP와 거래 기능이 있으면 등급이 올라갈 수 있습니다.

## 6. 「용의 귀환」에 대한 권고

### 6.1 포지셔닝

> **"설치 없이 링크 하나로, 확률형 없이, 친구와 드래곤을 잡는 MMO"**

| 축 | 대형 리니지라이크 | 「용의 귀환」 |
|---|---|---|
| 진입 | 수 GB 설치 | 브라우저 링크·PWA |
| BM | 확률형·P2W | **확률형 0%**, 외형·패스·후원 |
| 핵심 재미 | 공성·과금 경쟁 | **3인 역할 협동(전사·도적·신관) 드래곤 레이드** |
| 규모 | 수만 명 서버 | 200명 "동네 서버" = 서로 이름을 아는 커뮤니티 |

작은 서버 규모는 약점이 아니라 **"모두가 서로 아는 마을"**이라는 강점으로 내세울 수 있습니다(Tibia·OSRS 초창기, Hordes.io의 커뮤니티 운영과 같은 방식).

### 6.2 다음 기능 우선순위

| 순위 | 기능 | 이유 |
|---|---|---|
| **P0** | **서버 권한 저장·계정**(지금은 localStorage에 저장) | 기기를 바꾸면 캐릭터가 사라지는 구조로는 MMO가 성립하지 않고, 거래와 PvP의 부정행위도 막을 수 없음 |
| **P0** | **파티 시스템 + 파티 대상 힐·버프** | 신관의 존재 이유이자 레이드 협동의 핵심. 지금은 본인에게만 적용됨 |
| **P0** | 첫 30분 온보딩 다듬기(프롤로그→Lv15 진급) | 웹 게임은 D1 리텐션이 곧 생존. 업계 중앙값 D1 22%, 상위 25%는 약 27% ([GameAnalytics](https://www.gameanalytics.com/reports/2025-mobile-gaming-benchmarks)) |
| **P1** | 레이드 매칭(이그니스·바라카스) + 주간 초기화 + 랭킹 | 반복해서 다시 오게 만드는 장치이자 시즌 패스의 뼈대 |
| **P1** | 거래소 수수료(골드 싱크)·거래 기록·어뷰징 로그 | Albion식 경제. 인플레이션 방지 |
| **P1** | 외형 상점 + 무료·유료 시즌 패스(확률 없음) | 첫 매출. 가격을 시즌마다 **고정 공개**해 아이온2 같은 논란을 피하기 |
| **P2** | 생활 콘텐츠(낚시·채집·제작·하우징) | 마비노기 모바일이 증명한 수요. PvP를 싫어하는 이용자층 확보 |
| **P2** | Lv50 PvP는 **동의형**(결투장·전장)부터 | 강제 필드 PvP는 소규모 서버에서 신규 이탈을 부름 **[추정]** |
| **P3** | 영문 현지화 → itch.io·CrazyGames 라이트 빌드 | 해외 유입 테스트 |

### 6.5 리스크

- **1인 운영 부담:** GM, 신고, 버그 대응 → OSRS·Hordes.io처럼 커뮤니티 자원봉사 GM을 두고, 운영 도구(제재·로그)를 먼저 만들기

## 7. 참고 및 한계
